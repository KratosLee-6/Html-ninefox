## 📋 The 6 Required Screenshots

### 1. `hero.png` (主视觉 · 16:9)

- **Size**: 1600 × 900 px
- **Content**: Visual showing the 5-agent pipeline + 3 sinks + router at a glance
- **How to make**:
  - Option A: Use the ASCII diagram from README → convert to PNG via `asciitosvg` or `carbon`
  - Option B: Design in Figma (1600×900 frame, 5 colored boxes for agents, 3 boxes for sinks)
  - Option C: Render the actual pipeline in a browser (use `docs/ARCHITECTURE.md` HTML export)

### 2. `cli-demo.png` (终端 CLI 跑通截图)

- **Size**: 1200 × 800 px
- **Content**: Terminal showing `python -m fox.cli expert ...` running successfully
- **How to make**:
  - Run on Windows Terminal / iTerm2 / gnome-terminal with dark theme
  - Use Windows Terminal "copy text as image" or grab via Win+Shift+S
  - Show the 5 `✅` checkmarks from all 5 agents

### 3. `5-style-compare.png` (5 风格对照图)

- **Size**: 1600 × 900 px
- **Content**: 5 mini HTML renders side by side (swiss / brutalist / editorial / playful / corporate)
- **How to make**:
  ```bash
  for style in swiss brutalist editorial playful corporate; do
      python -m fox.cli expert \
          --brief examples/briefs/saas_landing.txt \
          --style $style \
          --output output/${style}.html
  done
  # Open all 5 in browser tabs → screenshot
  # Crop to 5 equal panels in Figma → save as 5-style-compare.png
  ```

### 4. `workbench.png` (工作台界面 · v0.3+)

- **Size**: 1400 × 900 px
- **Status**: ⏸️ Wait for v0.3 release
- **Content**: Web UI workbench with Brief editor + live preview

### 5. `sequence-diagram.png` (时序图)

- **Size**: 1400 × 800 px
- **Content**: Sequence diagram of 5 agents collaborating (user → brief → style → asset → generate → feedback → user)
- **How to make**:
  - Use https://www.plantuml.com/ or https://app.diagrams.net/
  - Style: clean, minimal arrows, labeled phases

### 6. `5-expert-pipeline.png` (5 智能体流水线图)

- **Size**: 1600 × 900 px
- **Content**: 6 expert CLI artifacts in a 2×3 grid (landing / dashboard / PPT / resume / poster / blog)
- **How to make**:
  - Render all 6 via `python -m fox.cli expert ...` with different briefs
  - Screenshot each HTML
  - Compose in Figma 2×3 grid → save
