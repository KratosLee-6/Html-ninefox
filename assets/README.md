# Assets · 视觉资产

This directory holds all visual assets for Html九尾狐's GitHub presence.

## 📁 Structure

```
assets/
├── README.md              (this file)
├── screenshots/           (PNG/JPG screenshots for README)
│   └── README.md          (screenshot checklist — see below)
├── demo.gif               (TODO [KX]: 60s screen recording of CLI run)
└── og-image.png           (TODO [KX]: 1200×630 social share image)
```

## 🖼️ What Goes Here

| File | Purpose | Format | Generated by |
|------|---------|--------|--------------|
| `screenshots/hero.png` | README hero image (16:9, ~1600px wide) | PNG | KX after first real CLI run |
| `screenshots/cli-demo.png` | Terminal capture of `python -m fox.cli expert` | PNG | KX (use Windows Terminal capture or asciinema) |
| `screenshots/5-style-compare.png` | Side-by-side of 5 styles (swiss/brutalist/etc) | PNG | KX — render 5 HTMLs, screenshot each |
| `screenshots/workbench.png` | Web UI workbench (v0.3 only) | PNG | Future |
| `screenshots/sequence-diagram.png` | Agent collaboration sequence | PNG | KX — use diagrams.net |
| `screenshots/5-expert-pipeline.png` | 6 expert CLI outputs in grid | PNG | KX |
| `demo.gif` | 60s screen recording | GIF | KX — use ScreenToGif / LICEcap |
| `og-image.png` | 1200×630 social share image | PNG | KX — design in Figma |

## 🎨 Naming Convention

- All lowercase
- Use hyphens, not spaces
- Include aspect ratio hint in comment if non-standard
- Examples: `hero.png`, `cli-demo.png`, `5-style-compare.png`
