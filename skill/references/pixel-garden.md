# 🎨 Pixel Garden 设计系统速查

> 出处：`docs/VI.md`（VI 手册 · Pixel Garden v1.0）、`docs/UI-GUIDE.md`、`htmlninefox/server/static/pixel-garden-tokens.css`
> 品牌方向：**A「像素花园」** · 核心口号：**让灵感在 HTML 里生长**

---

## 1. 品牌基调

| 维度 | 定调 |
|---|---|
| 关键词 | 灵感生长 · 结构编排 · 真实预览 · 精细像素 · 可靠交付 |
| 视觉气质 | 暖、理性、编辑感、轻技术、带少量像素识别 |
| 品牌语气 | 清楚、克制、鼓励行动；**避免玄学、夸张、「颠覆一切」式文案** |
| 品牌隐喻 | 不是「神秘 AI 黑盒」，而是一座**可观察、可编排、持续生长的数字花园** |

**推荐文案**：

- 「把素材拖进工作区，组合你的创作配方。」
- 「先看真实 HTML，再决定是否使用。」
- 「让灵感在 HTML 里生长。」

**禁用文案**：一键颠覆创作 / 全自动完美生成 / AI 魔法 / 无限可能。

## 2. 色板

### 2.1 主色

| 名称 | HEX | 角色 |
|---|---|---|
| Garden Cobalt | `#173C8F` | 主按钮、Logo、焦点结构、主连线 |
| Sprout Mint | `#49B894` | 成功、生长、辅助高亮、HTML 括号 |
| Paper White | `#FFFDF6` | 主面板、卡片、内容承载 |
| Warm Canvas | `#F4F0E7` | 浅色画布与页面底色 |

### 2.2 辅助色

| 名称 | HEX | 角色 |
|---|---|---|
| Clay Orange | `#E57A3F` | 鼻尖、焦点环、重要提醒 |
| Ink Navy | `#17283D` | 浅色主题正文 |
| Night Garden | `#10253B` | 夜蓝画布 |
| Night Panel | `#16314A` | 夜蓝面板 |
| Mist Gray | `#7A8A91` | 辅助文字 |

### 2.3 使用比例（**必须遵守**）

```text
60%  暖纸白 / 渐变灰画布
25%  深蓝文字与结构线
10%  钴蓝交互
 5%  薄荷绿与陶土橙状态提示
```

> ⚠️ **不要让钴蓝和薄荷绿同时大面积铺底**——
> 它们承担的是「**识别与反馈**」，不是制造视觉噪音。

### 2.4 语义色

| 语义 | 颜色 | HEX |
|---|---|---|
| Info（分析 / 上传 / 生成 / 等待） | 钴蓝 | `#173C8F` |
| Success（保存 / 生成 / 导出完成） | 薄荷绿 | `#49B894` |
| Warning（可恢复，需用户处理） | 陶土橙 | `#E57A3F` |
| Error（请求失败 / 数据不可用） | 柔和红 · 深陶土 | `#D96C4A` |

### 2.5 状态不能只靠颜色

状态必须**配合文字、勾选或序号**；标签用 **3px 小圆角**，不用超大胶囊。

### 3.3 兼容别名（旧产物迁移用）

老产物引用的 `hn-tokens.css`（靛蓝瓷）变量在 `pixel-garden-tokens.css` 里保留同名别名，
指向 Pixel Garden 值 → **零改动迁移**：

```css
--brand-primary: #173C8F;   --brand-bg: #F4F0E7;   --brand-text: #17283D;
--brand-accent: #2B4FA3;    --brand-bg-tint: #EDF3EC;
--brand-primary-soft: #76A5FF;  --brand-bg-paper: #FFFDF6;
--brand-on-dark: #F7F3EA;   --brand-hairline: rgba(23,60,143,0.16);
```

**用法**：产物里 `@import` 或 `<link>` 该文件即可。

## 4. 形状、圆角与投影

| Token | 值 |
|---|---|
| `--radius-sm` | `3px` |
| `--radius-md` | `5px` |
| `--radius-lg` | `6px` |
| `--shadow-pixel` | `3px 3px 0 rgba(23, 60, 143, 0.12)` |
| `--shadow-elev` | `4px 4px 0 rgba(23, 60, 143, 0.08)` |

**规则**（`docs/VI.md` §5 与 `UI-GUIDE.md` §5）：

- 圆角控制在 **3–5px**；**禁止**大面积 16–24px 的「AI 卡片圆角」。
- 控件圆角 `4px`；节点 `5px`；工作区 `6px`。
- 普通边框 `1px`；工作区虚线 `1.5px`；**焦点环 `2px`**。
- 默认阴影就是 **`3px 3px 0` 的轻像素投影**；浮层可用 `4px` 偏移。
- **禁止大面积模糊紫色光晕。**
- 基础像素视觉单位 `2px`；关键图标可用 `4px` 模块。

## 6. 字体系统

### 6.1 三种角色

| 层级 | 字体栈 | 用途 |
|---|---|---|
| **Display** `--font-display` | `Georgia, 'Noto Serif SC', 'Songti SC', serif` | 品牌标题、章节、营销短句 |
| **UI Sans** `--font-ui` | `Inter, 'PingFang SC', 'Microsoft YaHei', sans-serif` | 控件、正文、表单、导航 |
| **Mono** `--font-mono` | `'JetBrains Mono', Consolas, monospace` | 版本号、状态、代码、像素标签 |

**用法纪律**：

- 中文标题尽量 **12–24 字以内**，用衬线字体形成编辑感。
- **界面正文不用衬线字体**，保持快速扫描。
- Mono 只作**小面积识别**，不整段排中文。

### 6.2 界面字号层级

| Token | 字号 / 行高 | 用途 |
|---|---|---|
| Display | `24 / 32` | 空状态、品牌章节 |
| H1 | `18 / 26` | 页面标题 |
| H2 | `15 / 22` | 面板标题 |
| Body | `13 / 20` | 主界面正文 |
| Small | `11.5 / 18` | 节点、辅助信息 |
| Micro | `9.5 / 14` | 类型、状态、Mono 标签 |

**下限**：正文最小不低于 `11px`；**可点击文本不低于 `11.5px`**。

### 6.3 产物字号梯度（视觉系统用，非界面）

```css
--fs-hero: 96px;  --fs-h1: 56px;   --fs-h2: 40px;  --fs-h3: 32px;
--fs-lead: 26px;  --fs-body: 22px; --fs-meta: 16px; --fs-mono: 13px;
```

## 7. Logo 系统

| 资产 | 用途 | 文件 |
|---|---|---|
| 品牌符号 | 头像、按钮、角标、小尺寸识别 | `htmlninefox/server/static/logo-mark.svg` |
| 横版 Logo | 顶栏、官网页头、文档封面 | `htmlninefox/server/static/logo-horizontal.svg` |
| PWA 图标 | 浏览器、桌面安装、主屏幕 | `htmlninefox/server/static/icon.svg` |

**图形含义**：像素狐狸 + HTML 的左右尖括号。
狐狸 = 九尾狐的灵性与多形态；尖括号 = 结构化 HTML；薄荷绿像素 = 「生长」。

### 7.1 Logo 出现在哪里（工作台）

| 位置 | 用哪个 | 规格 |
|---|---|---|
| **顶栏左侧**（`.brand-lockup`） | `logo-mark.svg` | `32×32`，`image-rendering: pixelated` |
| 顶栏文字（`.brand-copy strong`） | 「Html九尾狐」 | Georgia / 15px / `letter-spacing: -0.02em` |
| 顶栏副标（`.brand-copy small`） | 「PIXEL GARDEN」 | Consolas 700 / **7px** / `letter-spacing: 0.18em` |
| **画布空状态**（`.canvas-empty .big`） | `logo-mark.svg` | 居中大图 |
| README / 文档封面 | `logo-horizontal.svg` | 宽 `430` |

- 顶栏 lockup `min-width: 174px`。
- **≤760px** 时隐藏 `brand-copy`，**只保留符号**（`@media` 规则）。

### 7.2 安全区

- 以品牌符号内部单个 `8px` 模块为 `1x`。
- 图形四周至少留 `1x`；**横版 Logo 四周至少留符号高度的 1/4**。
- 不让文字、边框、照片主体进入安全区。

### 7.3 最小尺寸

| 场景 | 最小 | 推荐 |
|---|---|---|
| 屏幕品牌符号 | `24×24px` | `32×32px` |
| PWA / 应用图标 | `48×48px` | — |
| 横版 Logo 宽度 | `144px`（更小就只用符号） | — |
| 印刷品牌符号 | `8mm` | — |

### 7.4 合法版本

- **暖纸白背景**：深钴蓝底品牌符号 + 标准横版 Logo。
- **夜蓝背景**：符号保持钴蓝底；文字切暖纸白，辅助字用雾灰。
- **单色场景**：只允许全钴蓝或全白，**不引入随机颜色**。

### 7.5 禁用方式

```text
❌ 不拉伸、不旋转、不加发光或 3D 金属效果
❌ 不把狐狸替换成 emoji
❌ 不把像素单元放大成粗糙游戏 UI
❌ 不改变钴蓝 / 薄荷绿 / 暖纸白 的角色关系
❌ 不放在低对比、复杂纹理或未经遮罩的照片上
```

## 8. 图标

- 三档尺寸：`16` / `20` / `24px`。
- 线宽 `1.5–2px`，端点优先**直角或小圆角**。
- 优先 SVG 或 CSS 图形；**emoji 不能作为主导航图标**。
- 同一工具栏保持一致线宽与视觉盒。
- 图标按钮**必须有 `title` 或 `aria-label`**。

## 9. 组件规范

### 9.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| **Primary** | 钴蓝底、白字 | 推进 / 生成 / 保存等**唯一主动作** |
| **Secondary** | 浅灰绿底 + 结构边框 | 新建工作区、打开预览 |
| **Ghost** | 默认不铺底 | 主题、诊断、帮助 |
| **Danger** | — | 删除与不可逆动作，**必须二次确认** |

禁用状态保持文字可读，**透明度不低于 45%**。

### 9.2 输入框

- 高度不低于 `28px`；移动端不低于 `32px`。
- `focus` 用**陶土橙 2px 外环**或钴蓝边框 —— 不只依赖颜色变浅。
- 错误提示**直接说明如何修复**，不用「未知错误」。

### 9.3 节点

- **标题栏是主要拖动区域**；正文输入控件不触发拖动。
- 选中使用 `1px` 强边框 + 外环，**不改变节点尺寸**。
- 端口在左右边缘；悬停和候选连接时扩大视觉反馈，但**不改变几何坐标**。
- 真实 HTML 预览保持**白色 iframe 画布**，避免主题样式污染产物。

### 9.4 工作区

- 必须有**名称、颜色、素材计数、推进动作**。
- 可从标题栏或空白区整体拖动；内部节点保持相对位置。
- **四种颜色只承担识别**，不改变主题语义色：

| ID | 名称 | HEX |
|---|---|---|
| `garden` | 像素花园 | `#173C8F` |
| `mint` | 薄荷苗圃 | `#49B894` |
| `clay` | 陶土信号 | `#E57A3F` |
| `night` | 夜蓝花园 | `#76A5FF` |

- 当前工作区在**列表和画布同时高亮**；一键定位必须可见。

### 9.5 检查器

内容顺序固定：

```text
对象名称 → 核心属性 → 主动作 → 危险动作 → 帮助
```

同一时刻**只编辑一个对象**；移动端改用右侧抽屉，带遮罩和明确关闭方式。

## 10. 动效原则

| 原则 | 要求 |
|---|---|
| **短** | 常规反馈 `100–180ms`；面板切换 `180–240ms` |
| **稳** | 节点不弹跳；拖动**不加装饰性惯性** |
| **可解释** | 吸附 / 对齐 / 连接必须通过辅助线和端口状态呈现 |
| **低干扰** | 减少循环发光；状态变化**只在发生时出现一次** |

---

## 11. 无障碍

- 正文与背景对比度不低于 **4.5:1**；大字不低于 **3:1**。
- 所有主要操作**可通过键盘到达**，`:focus-visible` 清晰可见。
- **不以颜色作为唯一信息**。
- 点击 / 触摸目标推荐 `32×32px`；移动端关键动作至少 `40×40px`。
- 遵循 `prefers-reduced-motion` 时**关闭非必要动效**。

---

## 12. 响应式断点

| 宽度 | 布局 |
|---|---|
| `≥1100px` | 三栏完整布局 |
| `761–1099px` | 素材栏 + 画布；检查器为抽屉 |
| `≤760px` | 画布为主；素材栏与检查器均为抽屉 |

**iOS 首阶段定位**：审阅、反馈、分享和轻编辑 —— **不强行塞入完整桌面画布能力**。

---

## 13. 摄影与插画

- **首选**：暖灰纸张、蓝图网格、植物生长、编辑桌面、网页结构局部。
- 图片上叠加信息时用**暖纸白半透明底**，**不使用纯黑遮罩**。
- 数据插画优先：**钴蓝主结构 · 薄荷绿结果 · 陶土橙异常**。
- 插画应呈现「材料、结构、生长路径」，避免无意义的**渐变球、光晕、机器人头像**。
