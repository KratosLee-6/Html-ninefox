> 生效范围：`v0.8.2` 及其后的 `main` 视觉基础切片
> 首次定稿：2026-09-01
> 最近校验：2026-10-20（v0.8.2 界面收敛，补动效、控件、图标、空态四节）
> 品牌方向：A「像素花园」
> 可执行契约：`docs/design-contract.json`（本手册的数值部分由 `tests/test_design_contract.py` 双向校验）

## 1. 品牌定位

Html九尾狐是一套把 Brief、审美模板、真实 HTML 预览和反馈迭代组合起来的创作工作台。品牌不表现为“神秘 AI 黑盒”，而表现为一座可观察、可编排、持续生长的数字花园。

- **品牌关键词**：灵感生长、结构编排、真实预览、精细像素、可靠交付。
- **视觉气质**：暖、理性、编辑感、轻技术、带少量像素识别。
- **品牌语气**：清楚、克制、鼓励行动；避免玄学、夸张和“颠覆一切”式文案。
- **核心口号**：让灵感在 HTML 里生长。

## 2. Logo 系统

| 资产 | 用途 | 文件 |
|---|---|---|
| 品牌符号 | 头像、按钮、角标、小尺寸识别 | `htmlninefox/server/static/logo-mark.svg` |
| 横版 Logo | 顶栏、官网页头、文档封面 | `htmlninefox/server/static/logo-horizontal.svg` |
| PWA 图标 | 浏览器、桌面安装、主屏幕 | `htmlninefox/server/static/icon.svg` |

Logo 将**像素狐狸**与 HTML 的左右尖括号组合：狐狸代表九尾狐的灵性与多形态，尖括号代表结构化 HTML，薄荷绿像素代表“生长”。

### 2.1 安全区

- 以品牌符号内部单个 8px 模块为 `1x`。
- 图形四周至少保留 `1x`；横版 Logo 四周至少保留符号高度的 1/4。
- 不让文字、边框、照片主体进入安全区。

### 2.2 最小尺寸

- 屏幕品牌符号：不小于 24×24px，推荐 32×32px。
- PWA / 应用图标：不小于 48×48px。
- 横版 Logo：宽度不小于 144px；小于该尺寸时只用品牌符号。
- 印刷品牌符号：不小于 8mm。

### 2.3 合法版本

- 暖纸白背景：使用深钴蓝底品牌符号与标准横版 Logo。
- 夜蓝背景：品牌符号保持钴蓝底；文字可切换为暖纸白，辅助字为雾灰。
- 单色场景：只允许全钴蓝或全白，不引入随机颜色。

### 2.4 禁用方式

- 不拉伸、不旋转、不增加发光或 3D 金属效果。
- 不把狐狸替换成 emoji，不把像素单元放大成粗糙游戏 UI。
- 不改变钴蓝、薄荷绿与暖纸白的角色关系。
- 不把 Logo 放在低对比、复杂纹理或未经遮罩的照片上。

## 3. 品牌颜色

### 3.1 主色

| 名称 | HEX | 角色 |
|---|---:|---|
| Garden Cobalt | `#173C8F` | 主按钮、Logo、焦点结构、主连线 |
| Sprout Mint | `#49B894` | 成功、生长、辅助高亮、HTML 括号 |
| Paper White | `#FFFDF6` | 主面板、卡片、内容承载 |
| Warm Canvas | `#F4F0E7` | 浅色画布与页面底色 |

### 3.2 辅助色

| 名称 | HEX | 角色 |
|---|---:|---|
| Clay Orange | `#E57A3F` | 鼻尖、焦点环、重要提醒 |
| Ink Navy | `#17283D` | 浅色主题正文 |
| Night Garden | `#10253B` | 夜蓝画布 |
| Night Panel | `#16314A` | 夜蓝面板 |
| Mist Gray | `#7A8A91` | 辅助文字 |

### 3.3 使用比例

- 60% 暖纸白 / 渐变灰画布。
- 25% 深蓝文字与结构线。
- 10% 钴蓝交互。
- 5% 薄荷绿与陶土橙状态提示。

不要让钴蓝和薄荷绿同时大面积铺底；它们应承担“识别与反馈”，而不是制造视觉噪音。

## 4. 字体系统

| 层级 | 字体建议 | 用途 |
|---|---|---|
| Display | Georgia / Noto Serif SC / Songti SC | 品牌标题、章节、营销短句 |
| UI Sans | Inter / PingFang SC / Microsoft YaHei | 控件、正文、表单与导航 |
| Mono | JetBrains Mono / Consolas / SFMono | 版本号、状态、代码、像素标签 |

- 中文标题尽量 12–24 字内，使用衬线字体形成编辑感。
- 界面正文不用衬线字体，保持快速扫描。
- Mono 只作小面积识别，不整段排中文。

## 5. 像素与图形语言

- 基础像素视觉单位为 2px；关键图标可使用 4px 模块。
- 网格以 16px 为主，4px 为微调单位。
- 圆角控制在 3–5px；不使用大面积 16–24px 的“AI 卡片圆角”。
- 图标采用 16 / 20 / 24px 三档，线宽 1.5–2px，端点优先直角或小圆角。
- 插画应呈现“材料、结构、生长路径”，避免无意义的渐变球、光晕和机器人头像。

## 6. 摄影与插画

- 首选暖灰纸张、蓝图网格、植物生长、编辑桌面、网页结构局部。
- 图片上叠加信息时使用暖纸白半透明底，不使用纯黑遮罩。
- 数据插画优先使用钴蓝主结构、薄荷绿结果、陶土橙异常。

## 7. 动效原则

- **短**：常规反馈 100–180ms，面板切换 180–240ms。
- **稳**：节点不弹跳，拖动不加入装饰性惯性。
- **可解释**：吸附、对齐、连接必须通过辅助线和端口状态呈现。
- **低干扰**：减少循环发光；状态变化只在发生时出现一次。

## 8. 品牌文案

推荐：
- “把素材拖进工作区，组合你的创作配方。”
- “先看真实 HTML，再决定是否使用。”
- “让灵感在 HTML 里生长。”

避免：
- “一键颠覆创作”“全自动完美生成”“AI 魔法”“无限可能”。

## 9. 资产维护

- SVG 为唯一源文件，不从 PNG 反向描摹。
- 修改 Logo、色板或字体时同步更新 `docs/VI.md`、`docs/UI-GUIDE.md`、PWA manifest 与截图基线。
- 第三方设计语言仅可在许可证明确时复用；当前 Huashu / Guizang 边界见 `docs/DESIGN-SOURCES.md`。

## 10. 动效（v1.2 新增）

一条时钟，五个档位，全部来自 `motion-system.js` 的 token，界面里不写裸毫秒。

| 档位 | 值 | 用途 |
|---|---|---|
| `--motion-instant` | 90ms | 按下位移、即时反馈 |
| `--motion-feedback` | 140ms | 悬停换面、状态点、徽标、浮条出现 |
| `--motion-enter` | 180ms | 元素进入、节点生成完成 |
| `--motion-panel` | 200ms | 弹窗与抽屉入场 |
| `--motion-exit` | 140ms | 退出（比进入短，收得干脆） |

规则：
- 只动 `transform` / `opacity` / 颜色，不动宽高、`top/left`、`flex-basis`。
- 按下比悬停更快（90 vs 140）：点击要有「立刻」感，悬停要「跟上」。
- 卡片悬停只换面，不移位 —— 像素风靠层与面区分，漂浮会破调性。
- 禁止 `transition: all`：会把布局属性一起动画。
- 「减少动效」偏好由 `motion-system.js` 统一接管，切到减少后动画数必须为 0，信息仍要完整（文字、百分比照常更新）。

## 11. 控件尺度（v1.2 新增）

| 档位 | 高度 | 用在 |
|---|---|---|
| 默认 | 32px | 面板内、卡片内、列表行 |
| 顶栏 / 弹窗 | 36px | 顶栏工具、弹窗底部主操作 |
| 移动 | 40px | ≤620px 视口下所有可点按钮 |

- 圆角：控件 3–4px，胶囊 999，圆形 50%；不使用 7px 以上圆角。
- 一屏只允许**一个**实心主操作（primary）；其余用 secondary / ghost。
- 五态必须显式：hover 换面、active 下移（位移复位、投影归零）、disabled 0.45 且不位移、busy 转圈、focus-visible 3px 环。
- 焦点环用 `--focus-ring`（钴蓝 9.92:1 / 夜蓝 #9BC0FF），**不用**陶土橙（对纸白仅 2.87:1，低于 WCAG 3:1）。
- 纯图标按钮：必须有 `aria-label`，可选同名 `title`；桌面 32×32、移动 40×40；状态切换不得改变尺寸。

## 12. 图标（v1.2 新增）

- 只有两档：**16px**（正文、列表、按钮内）与 **20px**（顶栏工具）。
- 线宽统一 **1.8**，端点圆头，`fill:none`，颜色继承 `currentColor`。
- 不在图标里塞文字；不用彩色图标，颜色由语义 token 决定。
- 像素投影是例外而不是默认：只允许出现在**选中节点**与**主按钮**两处。

## 13. 空态（v1.2 新增）

空态是起点，不是说明书。

- 一句话说明现状（不超过 20 字）+ **最多三个可点动作**。
- 动作必须真的能打开对应面板（有门禁：点一下就断言面板出现）。
- 不再罗列操作教程；教程属于文档，不属于空态。
- 检查器空态示例：「还没选中任何东西。先选一个起点：写一句需求 / 补充素材 / 新建工作区」。
