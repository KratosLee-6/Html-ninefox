# 私人 HTML 模板导入

Html九尾狐支持把已有 HTML 项目放进本地私人模板库。模板仅保存在当前输出目录的 `.library/gallery/`，不会自动进入 Git 仓库。

## 导入单 HTML

1. 打开工作台左侧“版式”。
2. 点击“导入单 HTML”。
3. 选择一个自包含 `.html` 或 `.htm` 文件。
4. 确认模板名称后，即可预览并拖入工作区。

## 导入完整文件夹

当 HTML 依赖 CSS、JavaScript、图片或字体时，使用“导入文件夹”。

- 系统优先选择 `index.html` 作为入口。
- 多个 HTML 会被识别为多个可抽取页面。
- 单 HTML 中的 `data-page`、`.page` 或 `.slide` 会被识别为页面。
- 系统自动提取常见颜色和字体，作为后续 Template DNA 的基础。
- 页面标题会映射为封面、问题、方案、数据、路线、表格等生成角色。
- 生成新作品时，私人模板的页面角色、主色和字体会参与生成，不只是作为截图参考。
- 不支持的无关文件会被跳过，不影响其余模板资源导入。

## 当前限制

- 单个模板包最多 120 个待处理文件。
- 实际复制资源总量不超过 24MB。
- 请求体不超过 36MB。
- 远程 CDN 资源仍依赖网络；建议把关键图片、脚本和字体放进模板文件夹。
- 当前不会自动清除客户名称或业务数据，公开分享前必须手动去敏。

## 推荐使用方式

- 市场调研长页面：导入单 HTML。
- 横向 PPT / Deck：导入包含 `index.html` 与素材的文件夹。
- 后台或产品原型：导入多个 HTML 页面组成的完整文件夹。
- 常用模板完成生成后会累计使用次数，在相同内容意图下逐步提高推荐优先级。
