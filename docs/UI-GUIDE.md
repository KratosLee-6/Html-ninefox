# Html九尾狐 UI 手册 · Pixel Garden v1.0

> 适用版本：v0.2.5+
> 适用客户端：Web / PWA，后续复用到 Windows、macOS、iOS。

## 1. 设计目标

1. 用户无需猜测模板：版式和风格必须显示真实 HTML 缩略图并支持放大。
2. 无限画布保持空间可信：拖动、吸附、连线、缩放使用同一世界坐标。
3. 多工作区可管理：始终提供列表、颜色、当前状态和一键定位。
4. 品牌辨识不妨碍生产力：像素只用于识别，界面主体保持清晰、紧凑。

## 3. 栅格与间距

- 画布主网格：16px。
- 基础间距：4px；常用序列：4 / 8 / 12 / 16 / 24 / 32。
- 顶栏：46px；移动端 52px。
- 左素材栏：216px；右检查器：264px。
- 控件高度：紧凑 24px、默认 28px、移动端 32px。
- 面板内部边距：8–14px；避免同层级混用过多间距。

## 4. 字号层级

| Token | 字号/行高 | 用途 |
|---|---|---|
| Display | 24/32 | 空状态、品牌章节 |
| H1 | 18/26 | 页面标题 |
| H2 | 15/22 | 面板标题 |
| Body | 13/20 | 主界面正文 |
| Small | 11.5/18 | 节点、辅助信息 |
| Micro | 9.5/14 | 类型、状态、Mono 标签 |

正文最小不低于 11px；可点击文本不低于 11.5px。

## 5. 形状、边框与阴影

- 控件圆角：4px；节点 5px；工作区 6px。
- 普通边框：1px；工作区虚线 1.5px；焦点环 2px。
- 默认阴影：`3px 3px 0` 的轻像素投影。
- 浮层可使用 4px 偏移阴影；禁止大面积模糊紫色光晕。

## 6. 图标

- 三档尺寸：16 / 20 / 24px。
- 优先使用 SVG 或 CSS 图形；emoji 不能作为主导航图标。
- 同一工具栏保持一致线宽与视觉盒。
- 图标按钮必须有 `title` 或 `aria-label`。

## 7. 组件规范

### 7.1 按钮

- Primary：推进、生成、保存等唯一主动作；钴蓝底、白字。
- Secondary：新建工作区、打开预览；浅灰绿底、结构边框。
- Ghost：主题、诊断、帮助；默认不铺底。
- Danger：删除与不可逆动作；必须二次确认或明确说明结果。
- 禁用状态保持文字可读，透明度不低于 45%。

### 7.2 输入框

- 高度不低于 28px，移动端不低于 32px。
- focus 使用陶土橙 2px 外环或钴蓝边框，不只依赖颜色变浅。
- 错误提示直接说明如何修复，不使用“未知错误”。

### 7.3 标签与状态

- 状态标签使用 3px 小圆角，不使用超大胶囊。
- 成功为薄荷绿、警告为暖黄、错误为砖红、处理中为钴蓝。
- 状态不能只用颜色；配合文字、勾选或序号。

### 7.4 节点

- 标题栏是主要拖动区域，正文输入控件不触发拖动。
- 节点选中使用 1px 强边框 + 外环，不改变节点尺寸。
- 端口位于左右边缘，悬停和候选连接时扩大视觉反馈但不改变几何坐标。
- 真实 HTML 预览保持白色 iframe 画布，避免主题样式污染产物。

### 7.5 工作区

- 工作区必须有名称、颜色、素材计数和推进动作。
- 可从工作区标题或空白区域整体拖动；内部节点保持相对位置。
- 六种颜色只承担识别，不改变主题语义色。
- 当前工作区在列表和画布同时高亮；一键定位必须可见。

### 7.6 工作区导航器

- 默认固定在画布左上角。
- 每行显示颜色、名称、素材数和编辑入口。
- 列表超过 240px 时内部滚动；收起状态持久化到工作区快照。

### 7.7 检查器

- 内容顺序：对象名称 → 核心属性 → 主动作 → 危险动作 → 帮助。
- 同一时刻只编辑一个对象。
- 移动端使用右侧抽屉，并提供遮罩和明确关闭方式。

### 7.8 当前工作区状态栏

- 只展示当前工作区的素材配方、视觉风格、需求、拆解、产物五阶段。
- 不再把整个无限画布压缩成全局时间轴。
- 移动端只保留阶段点，隐藏长标签。

## 8. 画布交互

- 拖空白区域平移；Ctrl/⌘ + 滚轮缩放；HUD 提供显式缩放。
- 节点与工作区使用统一世界坐标；DOM transform 不作为数据源。
- 默认 16px 网格吸附，并提供同边/中心辅助线。
- 按住 Alt 临时关闭吸附。
- 连线只在输入/输出端口间建立，松手前高亮候选端口。
- 拖动热路径使用 `requestAnimationFrame`；持久化发生在交互结束后。

## 9. 真实预览

- 版式、模板、历史文件使用真实 iframe 缩略图。
- 缩略图必须提供“放大预览”和“新窗口打开”。
- iframe 默认禁止编辑，避免拖动素材时误操作预览内容。
- 预览失败时显示明确占位与重试入口，不退回抽象线框让用户猜。

## 10. 无障碍

- 正文与背景目标对比度不低于 4.5:1；大字不低于 3:1。
- 所有主要操作可通过键盘到达，`:focus-visible` 清晰可见。
- 不以颜色作为唯一信息。
- 点击/触摸目标推荐 32×32px，移动端关键动作至少 40×40px。
- 遵循 `prefers-reduced-motion` 时关闭非必要动效。

## 11. 响应式

- ≥1100px：三栏完整布局。
- 761–1099px：素材栏 + 画布；检查器为抽屉。
- ≤760px：画布为主，素材栏和检查器均为抽屉。
- iOS 首阶段定位为审阅、反馈、分享和轻编辑，不强行塞入完整桌面画布能力。

## 12. 验收清单

- [ ] 默认主题为 Pixel Paper，刷新后主题偏好不丢失。
- [ ] 夜蓝主题无纯黑大面积背景。
- [ ] 125% 缩放后节点拖动无错位。
- [ ] 工作区整体移动时内部节点同步移动。
- [ ] 端口连线一次成功，候选端口有高亮。
- [ ] 所有 11 套风格均可看到真实 HTML 缩略图。
- [ ] 工作区名称、颜色和当前状态可持久化。
- [ ] 主操作键盘 focus 清晰，移动端抽屉可关闭。

## 12. Beta 2 创作路径

- 顶部“输入需求”是默认起点：文字、文档、图片 → 分析 → 推荐真实模板与页面。
- 用户采用推荐时，系统自动把模板和页面配方放入当前工作区并生成。
- 用户选择自定义时，需求与附件先进入工作区，再从版式、内容、风格、文件、技能中自由组合。
- “版式 / 内容 / 风格”卡片必须使用真实 HTML iframe；内容页支持从完整模板中单独抽取。
- AI 模型配置仅显示 Key 是否存在，不得把明文 Key 写入响应、工作区快照、项目状态或诊断包。
