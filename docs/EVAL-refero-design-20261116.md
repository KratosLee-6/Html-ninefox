# 评估 · Refero.design 作为设计参考源 + 模板视觉翻新批（0.9.8 之后的真话）

**日期**：2026-11-16
**触发**：机主看了 0.9.8 帖子的模板实拍后直言「这些模板都很丑」，给参考站
<https://refero.design/>（真实产品 UI/UX 截图库，按页面类型 / 流程 / UX 模式 /
UI 元素 / 站点五维组织，另有 MCP 接口）。**批评成立**，本评估不辩解。

---

## 一、丑的根因（自我诊断）

| 层 | 现状 | 差距 |
|---|---|---|
| 排版节奏 | 单一 clamp 字号 + 均匀 padding，无 8pt 网格、无字距微调 | 真实产品的 hero 有字重阶梯/负字距/行高对比 |
| 层次与深度 | 平面色块 + 1px 描边，几乎无阴影/光/景深 | 真实产品用多层阴影、渐变光、玻璃拟态分层 |
| 视觉元素 | 纯文字 + 色块，无图表/图形/产品截图/插画 | 真实产品页有真实数据可视化与产品影像 |
| 构图 | 全部居中对称 hero + 三列卡片 | 真实产品敢用不对称、超大字号、跨列网格 |
| 细节 | 无 hover 态/微交互/聚焦细节 | 「看起来 designed 而不是 generated」全在细节 |

**方法论错误**：0.9.8 的 9 张新模板是「契约骨架 + 色板换肤 + 文案填充」
的工程流程——骨架与内容对了，但**视觉系统没有设计输入**。老 10 张里
guizang 系（歸藏方法论）几张有气质，恰恰因为它们背后有一套设计方法论，
而不是色板表。

## 二、Refero 是什么 / 能怎么用

- **内容**：数万张真实产品界面截图（Linear/Stripe/Vercel 级别的产品），
  按页面类型（Dashboard/Landing/Paywall/About…）、流程（Onboarding…）、
  UX 模式（Testimonials/Dark Mode…）、UI 元素（Cards/Table/Skeleton…）、
  站点分类五维组织；提供 **MCP 接口**（「studies before it builds — and
  the output looks designed, not generated」——这句话就是我们缺的东西）。
- **许可红线**：截图内容版权归各原产品——**只学设计语言（排版节奏/层次/
  构图/密度），不复制资产（logo/文案/像素级布局）、不把截图放进产物或帖**。
  与 guizang 红线同一纪律：事实层可学，表达层自研。
- **接入形态选项**：
  a) **设计源清单**（零成本）：加进 `data/sources/design-galleries.yaml`
     作为灵感源，人工/agent 巡检参考——轻，立即可做；
  b) **联盟成员**（评估后）：Refero MCP 需要账号与密钥，属商业服务——
     做成联盟 manifest（guidance/design-reference 型）路由给配了 key 的用户，
     未装本地兜底。**待机主决定是否接**；
  c) **mood board 采集**（内部参考）：playwright 抓公开浏览页做内部参考板
     （不进仓库产物），供翻新批比对。

## 三、切分建议

| 批次 | 内容 | 规模 |
|---|---|---|
| **v0.9.9 内插「视觉翻新半批」** | ①设计源清单 + Refero 评估入档（本文件）②mood board 采集（Refero 公开页 + 现有设计源）③**翻新 Design Tokens 层**：排版节奏（8pt 网格/字重阶梯/负字距）、阴影与深度、细节清单——先在 3 张代表模板（landing/poster/dashboard）上重做视觉层，对照 Refero 参考板逐项比对 | ≈2 天 |
| **v0.9.10 视觉翻新全量** | 19 张全部按新 tokens 重做视觉层（骨架/内容/契约不动，只动 CSS 视觉系统）；翻新前后对照门禁（渲染协议不变） | ≈2-3 天 |
| 观察项 | Refero MCP 联盟接入（待机主确认账号成本）；`beautiful-html-templates` 34 套接入时同步用新 tokens 校准 | — |

## 四、诚实的话

0.9.8 帖子（周四发）里的模板就是现在的样子——帖子讲的是「选择面」
（数量/分组/筛选），视觉短板不回避：正文与置顶评论不出现「好看/精美」类
形容词（已核对：现有文案没有这类词）。视觉翻新批落地后，**下一帖的素材
自然会好看**——用 before/after 对比反而是更好的故事。
