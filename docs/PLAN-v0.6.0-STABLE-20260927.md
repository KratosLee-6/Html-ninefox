# v0.6.0 正式版迭代计划

- 制定日期：2026-09-27
- 起点：`v0.5.0` 稳定版（含 macOS 包、intake 前三步地基）
- 主题：**设计吸收流水线 + 可编辑 PPTX**
- GitHub 总追踪：Issue #7
- 目标发布日：**2026-11-08 前后**（窗口 11-01 ～ 11-14）
- 预计投入：20～28 个有效工作日
- 迭代方式：本计划拆分为 **编号步骤（V0.6-Sxx）**，每步独立闭环（实现 → 测试 → 落地 → CI 绿 → 勾销），**以 v0.6.0 发布为最终完成标志**

## 零-A、v0.6.0 要达成的内容（成果定义 G1–G6）

大版本交付以以下六项用户可感知成果为判定基准；所有步骤（S04–S21）都映射到这些成果，不服务成果的工作不做。

| # | 成果 | 达成判定 |
|---|---|---|
| **G1** | **三条吸收通道可用**——手动粘贴/批量、内置源抓取、AI 分析，任何人都能把外部优秀设计变成候选素材 | 从「源 → 安全抓取 → 审核台候选」全流程可走通且留证据；批量入口（多 URL / ZIP）可用 |
| **G2** | **审核台安全治理**——许可三档标识、沙箱预览、批量采纳/拒绝、来源筛选 | 不安全候选（私网抓取/畸形 HTML/路径穿越）无法入库；预览不执行候选脚本 |
| **G3** | **六资产层贯通**——模板、风格、组件、装饰、动效、内容全部有「吸收→审核→入库→工作台可用」链路 | 每层 ≥1 条真实入库素材被工作台选用并生成原创产物 |
| **G4** | **可编辑 PPTX**——deck 导出 PPTX，PowerPoint / WPS 打开文本可编辑 | 导出报告列明可编辑元素数与降级项 |
| **G5** | **质量性能不退化**——267+ 测试、双引擎 e2e、WebKit 通道、100 节点 / 20 revisions、吸收压测 100 候选 | 全部门禁绿且数据入 docs/test-evidence |
| **G6** | **发布工程完备**——六平台附件 + SHA-256 回读一致，中英文档/截图与真实版本一致 | check_release_version --tag v0.6.0 通过；回读校验记录入库 |

## 零-B、小步快跑迭代方式

- 每步 ≤2 个有效工作日；独立闭环：实现 → 测试 → 落地 → CI 绿 → Issue #7 勾销
- 任何步骤超期即拆半步；每步落地即可用，不依赖未完成步骤
- 里程碑门禁：M1 吸收通道全通（10-08）→ M2 六层贯通（10-18）→ M3 PPTX 可用（10-25）→ M4 功能冻结（11-01）→ **M5 稳定化 7 天（11-01～11-07，只修阻断级 bug）** → 🎉 v0.6.0 发布（11-08 前后）
- 偏差处理：DOCX（S15）与 Tauri 允许顺延/出列，不阻塞发布判定

## 零-C、完美交付标准（可用性门槛）

1. 核心路径零阻断 bug：输入 → 生成 → 预览 → 反馈 → 导出/分享 → 吸收新素材 → 再创作
2. 新功能「三有」：有文档、有截图、有测试
3. 稳定化窗口（M5）无新增阻断 bug
4. 退出条件七条（见「v0.6.0 发布退出条件」）全部满足

## 六、每步完成条件（沿用 v0.5 闭环）

1. 可验收的纵向用户能力；
2. 该步测试齐备（单元 + 集成 + 需要时浏览器验收）；
3. 全量 pytest 回归通过；
4. CHANGELOG/相关文档同步；
5. 提交推送（经已授权的 GitHub API 通道）→ main CI 绿 → 本清单勾销。

## 七、v0.6.0 发布退出条件

- 从内置源完成完整吸收演练：抓取 → 审核 → 模板/风格/组件各 ≥1 入库 → 工作台选用并生成原创产物；
- 每条素材可追溯（来源/许可/时间/摘要）；SSRF 与限速用例全绿；
- PPTX 在 PowerPoint/WPS 打开且文本可编辑，降级项列报告；
- 性能与既有门禁不退化（S16/S17/S18 证据入库）；
- 六平台附件 + SHA-256 齐备且回读一致；中英文档与真实版本一致。

## 八、风险与对策

| 风险 | 对策 |
|---|---|
| 版权模糊 | 许可三档强制；模糊来源一律 inspiration-only；只提取令牌/骨架，产物原创重渲染 |
| 源站改版致适配器失效 | 适配器按源隔离可单独禁用；源清单支持用户目录覆盖与热更新 |
| 素材噪声堆积 | 审核台人工把关 + adoption 使用信号自然淘汰；压测门禁保证规模不伤性能 |
| PPTX 兼容性长尾 | 受控映射白名单起步；降级项透明写入报告 |
| 范围蔓延 | DOCX（S15）与 Tauri 允许顺延/出列，不影响 v0.6.0 发布判定 |

## 九、移动端决策记录（2026-09-26 用户确认）

原生安卓 / iOS 包**缓发，等真实需求**；移动端以 PWA（局域网 + 添加到主屏幕）与导出长图分享为准。capabilities 中 `ios: planned / android: later` 维持。v0.6 不投入原生移动打包资源。
