# Html九尾狐 · v0.4 产品迭代与竞品拆解

> 日期：2026-09-03  
> 基线：v0.3.0b2 已发布  
> 结论：下一阶段不应继续横向堆客户端和模板数量，而应建立“私人模板 → 项目记忆 → 反馈评分 → 下次推荐”的本地复利闭环。

## 1. Executive takeaway

1. **无限画布只是操作层。** ComfyUI 与 tldraw 的价值在稳定坐标、选择、连线、历史记录和扩展机制；九尾狐必须继续补齐撤销重做、框选、组合、搜索定位和小地图，否则复杂项目仍会失控。
2. **Coze 类产品的优势是编排可解释。** 节点不只摆在画布上，还要能看输入、输出、运行状态、错误和重跑范围。九尾狐需要把一次 HTML 生成变成可追踪的 Recipe Run。
3. **真正的差异化是长期积累。** 直接竞品擅长即时生成，九尾狐更适合成为本地优先的 HTML 创作资产库：每次导入、选择、生成、修改和反馈都能提高下一次推荐质量。

## 2. 定位图

横轴：从“通用工作流基础设施”到“可交付 HTML 成品”。  
纵轴：从“一次性即时生成”到“长期个人资产积累”。

| 产品 | 横轴位置 | 纵轴位置 | 核心价值 |
|---|---|---|---|
| tldraw | 工作流基础设施 | 中 | 无限画布交互与可扩展图形系统 |
| ComfyUI | 图像工作流 | 高 | 工作流 JSON、节点生态、模板复用 |
| Coze Studio | Agent 编排平台 | 中高 | Workflow、知识、插件、发布与调试 |
| Lovable 类生成器 | 可交付应用 | 中 | 对话生成、项目知识、视觉修改 |
| Html九尾狐 | 可交付 HTML | 目标高位 | 本地模板、可视编排、真实预览、反馈沉淀 |

## 4. 三个本地样例能沉淀什么

### 4.1 服装市场调研交互版

- 形态：单 HTML 长篇交互报告。
- 可沉淀：章节导航、证据登记、数据矩阵、结论摘要、长页面阅读节奏。
- 应转化为：`interactive-report` 模板家族，而不是复制客户名称和业务数据。

### 4.2 咖啡庄园建设规划

- 形态：单 HTML、16 页横向演示稿。
- 可沉淀：封面、问题、方案架构、阶段路线、报价、结尾等页面角色。
- 应转化为：页面级模板包，允许只抽取某一页加入新工作区。

### 4.3 供应链原型

- 形态：12 个 HTML 页面组成的后台与业务原型。
- 可沉淀：后台导航、KPI、表格、知识库、聊天、文件处理、时间线和部署页。
- 应转化为：多页面 Prototype Kit，可整套复用，也可单页抽取。

## 5. 复利闭环

```text
导入 HTML / 文件夹
  → 自动识别页面、颜色、字体和形态
  → 用户在工作区组合并生成
  → 记录实际选用模板、页面和技能
  → 收集“保留 / 删除 / 修改”反馈
  → 形成项目记忆与成功配方
  → 下一次优先推荐真实高成功率组合
```

建议新增四个核心对象：

- `TemplatePackage`：HTML、资源、页面地图、设计 Token、来源与隐私范围。
- `ProjectMemory`：品牌规则、固定素材、偏好、禁忌、历史决策和目标受众。
- `RecipeRun`：输入、节点版本、模板组合、运行日志、产物与耗时。
- `FeedbackSignal`：喜欢、保留、删除、手动修改、回滚和最终采用情况。

## 6. 机会窗口

### A. 私人 HTML 资产库

- Why now：用户已有大量散落 HTML，但无法在下一次创作中继续利用。
- First move：本地导入单 HTML 或完整文件夹，自动生成页面清单与设计 Token。
- 风险：客户数据误入公开仓库；必须默认只保存在本地。

### B. 可解释的创作运行记录

- Why now：当前只看到最终产物，失败时不知道是哪一步出错。
- First move：节点状态、输入输出摘要、局部重跑、执行耗时和失败原因。
- 风险：日志过多会增加复杂度；默认只展示当前失败链路。

### C. 从模板推荐升级为个人推荐

- Why now：模板数量增加后，搜索与选择成本会重新上升。
- First move：意图匹配 + 使用次数 + 最终采用率 + 最近使用时间的本地评分。
- 风险：早期样本少；允许固定、降权和清除学习记录。

## 7. 行动路线

### 30 天：易用性

- [x] 私人模板包导入：单 HTML / 完整文件夹。
- [x] 包内 CSS、图片、脚本和字体安全复制与预览。
- [x] 多 HTML 页面识别、单页预览和使用次数记录。
- [x] 画布撤销/重做、框选、多选移动、组合与锁定。
- [x] 小地图、全局搜索和命令面板。
- [ ] 快捷键帮助面板与首次使用引导。
- [ ] 模板收藏、最近使用、置顶与标签编辑。

### 90 天：可用性

- [ ] Project Memory：品牌、受众、语气、禁忌、常用素材。
- [ ] Recipe Run：逐节点状态、局部重跑、输入输出摘要。
- [ ] 产物版本树、差异对比、命名版本和一键回滚。
- [x] 从 HTML 抽取基础页面角色，并让颜色与字体进入生成。
- [ ] 继续抽取可编辑组件 DNA、布局约束和交互行为。
- [ ] 浏览器、桌面、平板三档实时预览与截图验收。

### 180 天：长期复利

- [ ] 本地推荐评分与可解释推荐理由。
- [ ] 工作区保存为可复用配方 / 子流程。
- [ ] 私人模板包导出、分享、签名与版本兼容检查。
- [ ] 可选端到端加密同步，不改变本地优先原则。
- [ ] 社区模板市场只接收去敏、带来源与许可证的模板包。

## 8. 当前已落地

- 新增 `UserGalleryStore`，支持安全导入、原子写入和资源复制。
- 图库 API 同时返回内置模板与私人模板。
- 工作台版式栏可导入单 HTML 或整个文件夹。
- 私人模板可整套预览、多页抽取和本地删除。
- 成功使用后累计 `usage_count`，同意图下优先推荐真实常用模板。
- 三个用户样例已完成临时导入演练，未把客户内容提交进公开仓库。

## 9. Evidence gaps

- 本轮未做竞品付费层级比较，因为产品形态和部署方式差异过大，价格不应成为当前决策依据。
- 使用次数只是第一阶段信号，还不能代表最终满意度；下一步需要“最终采用 / 手动删除 / 回滚”信号。
- 复杂 HTML 的页面识别目前依赖多文件、`data-page`、`.page` 或 `.slide` 结构，后续需增加 DOM 语义分析。
