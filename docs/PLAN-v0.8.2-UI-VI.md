## 1. 取证：现在到底哪里不对（全部实测）

### 1.1 手册与实现已经漂移 —— VI/UI v1.1 停在 2026-09-24

手册写完之后，v0.7.x → v0.8.0 三个版本一直在改界面，**没有回头改手册**。逐条比对：

| 项 | 手册承诺（VI/UI v1.1） | 代码实测 | 判定 |
|---|---|---|---|
| 顶栏高度 | 桌面 52px / 移动 56px | `grid-template-rows:46px …`（移动 `52px`） | ❌ 差 6px / 4px |
| 界面正文 | Body `13/20` | `--fs-md:12px`（33 处使用） | ❌ 小一档 |
| 最小文字 | 「正文最小不低于 11px，可点击文本 ≥11.5px」 | `--fs-xs:10px` × **21 处**、`--fs-2xs:9px` × 1 处 | ❌ 22 处低于自家下限 |
| 控件高度 | 紧凑 32 / 常用 36 | `.btn` **28px**、`.search` 27px（弹窗内 34/36） | ❌ 三套并存 |
| 圆角 | 控件 3–5 / 节点 5 / 工作区 6，「不使用超大胶囊」 | 2、3、4、5、6、7、8、10px 并存，另有 `999px` × 3 | ❌ 无刻度 |
| 间距 | 全部走 `--space-*` | `index.html` **89 处** px 字面量（**63 处脱 4/8/12/16 网格**）；`workbench-system.css` 35 处（19 处脱网格） | ❌ ROADMAP 第 314 行「间距 142 个值走 token」与实测不符 |
| 颜色唯一来源 | 品牌色只来自 VI 色板 | `:root` 之外 **9 个非 token 十六进制**：`#D35D5D` `#5a6473` `#e5e2d8` `#3c4552` `#1f6f57` `#78958B` `#BAC8BD` `#DFE6D9` `#1F795E`；另有 `fox-core.js` 内联 `#fff` | ❌ 色漂移 |
| Display 字体 | 「中文标题用衬线形成编辑感」 | Georgia 只在 `.recommend-title` **1 处**出现，工作台所有标题都是无衬线 | ❌ 品牌语气未落地 |
| 级联可校验性 | 手册数值 = 实现数值 | 存在**后置补丁层**覆盖前文：`.meta-chip/.rev-chip` 先 `999px` 后 `3px`；`.node iframe` 先 `9px` 后节点 `5px`；`.tab` 先 `6px` 后 `3px` | ❌ 最终值靠层叠顺序，audit 量的不是作者本意 |

> **根因**：手册没有门禁。它是一份文档，不是一个可执行的契约 —— 所以三个版本就能把它写旧。

## 2. 版本目标与验收总纲

**一句话**：不换主题、不改品牌色、不加功能 —— 把 Pixel Garden 的执行层补齐。

| 目标 | 定义 | 怎么判 |
|---|---|---|
| **T1 手册即代码** | 手册里每个数字都能在代码找到 token；代码里没有手册外的值 | 新增契约门禁双向比对，漂移即红 |
| **T2 版面有层级** | 每个界面 ≤2 层边框、1 个主 CTA、空态必有下一步 | DOM 度量门禁 |
| **T3 真实预览可用** | 216px 卡宽下缩略图的主色调与版式可辨，放大入口常显 | 渲染尺寸阈值 ＋ 截图评审 |

**明确不做**：换主题 / 改品牌色（Pixel Garden 是既有资产，只优化迭代）· 业务功能 · 六类产物模板视觉重写 · Tauri · 键盘可达性专项（v0.8.3）。

## 4. 顺序与节奏

```
B1（取证）
  ↓
B2（token 收敛 · 用户几乎无感，但门禁全绿）
  ↓
```

**合计约 6.5 人日**，按「小步快跑、每周 1 件事」拆成两个发布点：

## 5. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 2px 间距位移改变呼吸 | 紧凑工具界面对 2px 敏感，一次全改会「说不上哪里不对但整体变松」 | 分批提交 ＋ 每批截图对比，由 KX 只看差异图 |
| 手册继续漂移 | 双写没有门禁是根因 | B5-1 契约门禁是长期解法，不是本版一次性功课 |
| 发布阻断 | `verify_portable.py` 的内容标记断言会撞 B2 的 token 改名 | B5-5 与本版同时完成 |
| 夜蓝主题回归 | 历史 bug：写死 `#fff` 压亮蓝底只有 2.44:1 | 所有改动必须双主题跑对比度门禁 |
| 范围蔓生 | 六类产物模板视觉、生成器 `generators/_shared.py` 不在本版 | 只动工作台外壳；产物令牌文件另立决策（接进产物 or 降级为 docs 参考） |
