# 间距收敛对照证据（2026-09-29）

第二步把 `10 / 6 / 14 / 18px` 吸到 4px 网格的**改动前后**实拍对比。

## 方向决策

四个值到最近网格值都是 ±2px 的平局：

| 原值 | 候选 | 采用 | 理由 |
|---|---|---|---|
| 10px | 8 / 12 | **8px** | 密集工具界面（顶栏 56px、控件 28–36px），收紧更紧凑；留白交给 `--space-4` / `--space-6` |
| 6px | 4 / 8 | **4px** | 同上 |
| 14px | 12 / 16 | **12px** | 同上 |
| 18px | 16 / 24 | **16px** | 唯一解 |

平局一律取较小值。若评审后偏好宽松，改
`.codex_tmp/apply-space-step2.py` 的 `TABLE` 目标值重新运行即可。

## 实际改动量

**40 个值**（不是先前估的 60）——多值混合声明（`gap: 0 10px`、`padding: 2px 8px`）
因含不可映射的成分被整体跳过，没有做部分改写。

`2px` 未动：它是给 1px 描边做偏移的发丝线，不在网格上是对的。
