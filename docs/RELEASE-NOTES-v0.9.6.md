## 二、主线可用性巡检（本版新增纪律）

`scripts/verify_mainline.py`：真实 serve + 离线规则引擎，12 项功能真链
验证（health/workflows/analyze/generate/recipe-run/feedback/voice/polish/
画廊/PDF/交付包字体子集）。**发版前必跑**。

**首跑抓出三个真 bug（全部修复 + 门禁）**：

1. **feedback 相对项目名未走 resolve_project**——`.foxstate.json` 存在却报
   422「项目缺少 .foxstate.json」。现相对名 resolve、绝对路径直传（兼容既有
   调用方）。
2. **recipe-run GET 端点字段白名单丢 compose `output_summary`**——剧本留痕
   到不了 UI 时间线（0.9.4 端到端测试当时绕行读文件，现改回直断言端点）。
3. **`apply_feedback` 顺序缺陷**——「主色改成 #xxx」同轮命中 hex_color 与
   color_shift，shift 在 OKLCH 收域后把主色拽出域（#00FF00→#3ED535，
   L=0.77）。override 改为 rules 之后落定，最终以收域为准。

另：交付包 API 返回补 fonts 报告；guidance-source 联盟成员不再进产物路由
候选（字典序平分抢占，CI 实锤）；`[font]` extra brotli 下限放宽到 1.1
（Python 3.14 无 wheel 会炸 uv 全量解析）。
