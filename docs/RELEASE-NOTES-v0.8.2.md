# v0.8.2 · 界面收敛

**发布日期**：2026-10-20
**主题**：不换主题、不改品牌色。把 Pixel Garden 的**执行层**补齐 —— 用「面」分层
而不是描边围框，按钮、动效、空态、图标按一套尺度收口，并让这些尺度可以被机器检查。

---

## 一、这次解决的四个问题

| 问题 | 过去的样子 | 现在 |
|---|---|---|
| 满屏黑线框 | 每个面板、卡片、输入框都描深色边 | 边界改为墨色 10% / 17% / 30% 三档透明度，结构交给底色与两级柔和投影 |
| 按钮各写各的 | 高度 26–40 不等，状态只有 hover | 32 默认 / 36 顶栏 / 40 移动；hover、active、disabled、busy、focus-visible 全部显式 |
| 动效凭手感 | 140 / 180 / 220 / 250ms 混用，还有 `transition: all` | 一条时钟：instant 90 / feedback 140 / enter 180 / panel 200 / exit 140，全部 token |
| 空态是说明书 | 检查器三行小字「选中节点查看属性」 | 一句话 + 三个可点起点（写需求 / 补素材 / 新建工作区） |

## 二、可访问性修复（这版挖到的真 bug）

焦点环原本用陶土橙 `#E57A3F`。实测对暖纸白 **2.87:1**、对纸白 **2.57:1**，
低于 WCAG 1.4.11 对非文本 UI 的 **3:1** 要求 —— 键盘用户看到的是一个几乎不显眼的环。

改为钴蓝后 **9.92:1 / 8.88:1**，并使用 `--focus-ring` 独立 token（浅色钴蓝、夜蓝 `#9BC0FF`），
`--focus` 只留给选区与装饰。门禁不再是写死常量，而是**现场算相对亮度**。

## 三、设计契约（这版新增的工程能力）

`docs/design-contract.json` 是唯一数值来源，`tests/test_design_contract.py` 双向比对：

- 代码里的 token 值必须与契约一致（改代码不改契约 → 红）
- 契约里的每个 token 必须真的在 CSS 里（删代码不改契约 → 红）
- 硬规则：字号 ≥ 11px、圆角 ∈ {3,4,5,6,999,50%}、裸 hex ≤ 2 处（均有理由）、间距不得变差

间距目前有 **109 处**脱 4/8 网格，作为 burn-down 基线记录，只禁止变差，不在这版一次改完。

## 四、门禁与证据

| 门禁 | 内容 |
|---|---|
| 设计契约 | token 双向一致、字号/圆角/裸 hex/间距四条硬规则 |
| 按钮系统 | 尺寸、五态、四变体、一屏一个实心主操作、纯图标可访问名与点击区 |
| 动效 | 时长只能来自 token、禁用 `transition:all`、面板入场 ≈200ms、卡片不位移 |
| 素材脱敏 | 截图与示例只允许虚构主体「星野智造／栖木云」，黑名单在仓库外 |

## 五、升级说明

- 无数据迁移：工作区、产物、导出格式都不变
- 若你本地改过 CSS：请以 `docs/design-contract.json` 为准同步数值，否则门禁会红
- 减少动效偏好沿用 v0.7.6 的开关（系统 / 减少 / 关闭），这版实测「减少」下动画数为 0
